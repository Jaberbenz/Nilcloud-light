# Networks

Cette section explique la configuration réseau utilisée dans les déploiements Ansible avec Docker.

---

## Configuration du réseau

Un réseau Docker spécifique est utilisé pour faciliter la communication entre les conteneurs :

```bash
# Création du réseau Docker
docker network create --subnet=172.20.0.0/24 --gateway 172.20.0.1 --driver bridge net-ansible

# Vérification de la configuration du réseau
docker network inspect net-ansible
```

## Objectif du réseau

- Faciliter la communication entre les conteneurs Ansible Master et Slave.
- Garantir une connectivité stable pour les exécutions de playbooks et la gestion des rôles.

### Conteneurs connectés

1. **Master** : Conteneur principal pour l'exécution des commandes Ansible.
2. **Repo** : Conteneur slave hébergeant les rôles et fichiers requis.
